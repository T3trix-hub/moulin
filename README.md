# Мулен — сайт-макет

Статический сайт (HTML, CSS, JS), без сборки: `index.html`, `menu.html`, `about.html`, `faq.html`, `contacts.html`.

## Запуск
Откройте `index.html` в браузере или `python3 -m http.server 8000`. Шрифты (Marck Script, Lora) и карта грузятся из интернета.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в корень все файлы папки.
2. Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
3. Сайт откроется на `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

## Что править
- **Цены:** в `menu.html` замените `цена — уточняйте` у каждой позиции.
- **Контакты:** телефон, Telegram и Facebook прописаны в HTML (поиск по `796-74-33`, `moulin_chechota`).
- **Карта:** `text=` в `<iframe>` на `contacts.html`.
- **Цвета и шрифты:** переменные в начале `style.css`.
- **Фишка «Набор к кофе»:** список берётся из позиций меню в `menu.html` (блок `<ul class="set">`); логика в `main.js`.

- **Табличка «Открыто / Закрыто»** (главная): часы 07:30–21:30 заданы числами 450 и 1290 (минуты от полуночи) и текстами в `main.js`; при смене графика поправьте их.
